# Aula 1 — Introdução a Algoritmos

## Introdução aos Algoritmos

- Foi apresentado o conceito de algoritmo de forma simples e aplicada ao cotidiano, mostrando que algoritmos estão presentes em tarefas rotineiras realizadas pelas pessoas.

### Conceito de Algoritmo

* Algoritmos são conjuntos de passos finitos e organizados que, quando executados, resolvem um determinado problema.

---

### Algoritmos Computacionais

- Também foi abordada a diferença entre:

	- **Algoritmos comuns**
	- **Algoritmos computacionais**

### Definição de Algoritmos computacionais

- Algoritmos computacionais são passos executados por um **módulo processador** e seus respectivos **usuários** que, quando realizados na ordem correta, conseguem executar determinada tarefa.

---

## Variáveis

As variáveis foram explicadas utilizando um exemplo figurativo:

* A memória do computador foi comparada a um **armário**.
* Cada espaço desse armário representa uma variável.
* Cada variável possui:

  * Um **identificador** (nome)
  * Um **tipo**
  * Um valor armazenado

### Definição de Variáveis

- Variáveis são espaços na memória utilizados para armazenar valores.

---

## Identificadores

### Definição

- Identificador é o nome utilizado para identificar uma variável.

---

## Tipos Primitivos no Visualg

- Os quatro tipos primitivos apresentados foram:

| Tipo      | Descrição                   |
| --------- | --------------------------- |
| Inteiro   | Números inteiros            |
| Real      | Números reais               |
| Caractere | Textos e caracteres         |
